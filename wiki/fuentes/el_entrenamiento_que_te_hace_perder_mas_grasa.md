# El Entrenamiento que te hace Perder Más Grasa

## Resumen
El Dr. Borja Bandera explica qué tipo de intensidad de ejercicio es más efectiva para perder grasa y preservar músculo, especialmente después de los 50 años. Desmonta el mito de que solo se debe hacer cardio suave y propone una combinación de alta intensidad (sprints) para movilizar grasa y preservar fibras rápidas, seguida de baja intensidad (Zona 2) para oxidar esa grasa.

## Puntos Clave
- **Sarcopenia**: Pérdida de 1-2% de músculo anual tras los 50 años. El músculo es clave para el cerebro, la glucosa y la quema de grasa pasiva.
- **Nutrición vs Ejercicio**: "Se come para perder grasa, no se entrena para perder grasa".
- **Entrenamiento Polarizado**: El combo de Sprints (alta intensidad) para movilizar grasa y Zona 2 (baja intensidad) para oxidarla es el más eficiente.
- **Beneficios del HIIT**: Suprime el apetito (grelina), activa mTOR y preserva fibras tipo 2.
